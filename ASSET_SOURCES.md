# Asset sources

Every visual on the site is either **supplied by the site owner** or **drawn in
code**. There is no purchased stock imagery, no scraped artwork and no
third-party brand mark used as decoration. This file records the provenance of
each asset so the claim can be checked.

## Drawn in code (nothing downloaded)

These are rendered at runtime and have no image file behind them:

- **Hero cosmic system** — `src/components/effects/starfield.tsx` (Canvas2D
  depth-layered stars + shooting stars) and
  `src/components/effects/aurora-field.tsx` (OGL fragment-shader colour field),
  plus the CSS nebula bands, light shafts, grid and the animated orbital path
  composed in `src/components/sections/hero.tsx`.
- **Lab experiments** — six interactive demos in
  `src/components/sections/lab/experiments/` (magnetic button, text distortion,
  cursor trail, shader field, particle field, scroll reveal). All canvas/DOM,
  drawn from scratch.
- **Technology banners** — `src/components/sections/tech-banners.tsx`, each
  scene pure CSS/SVG.
- **Project signatures** — `src/components/sections/project-signature.tsx`,
  code-generated per-slug tiles used when a project has no still.
- **Texture and chrome** — grain, hairline rules, grid washes and the vignette
  live in `src/app/globals.css`.

## Libraries (open source)

Used as code, not as bundled artwork. Licences are those of the packages in
`package.json`:

- Fonts via `next/font/google`: **Bricolage Grotesque**, **Geist**,
  **JetBrains Mono** (SIL Open Font License).
- Icons via **lucide-react** (ISC).
- Rendering/runtime: **Next.js**, **React**, **Tailwind CSS**, **GSAP**,
  **Motion**, **Lenis**, **OGL**, **Drizzle ORM**, **Zod**, **Radix UI**.

## Deliberate omissions

- **No hardware imagery.** The Uses section does not invent a desk setup; there
  is no stock photo of someone else's keyboard standing in for the owner's.
- **No licensed hero background.** The original brief allowed for a licensed
  internet asset, but a code-drawn field keeps the page light, animatable and
  free of attribution constraints — so the code was kept.

## Internet-asset review (master redesign brief, Part 19)

External sources (Unsplash/Pexels/LottieFiles/SVG repos) were considered
against the selection criteria. Decision: **no external downloads.**

- The hero/about portraits, product stills and demo loops above are the
  owner's own material — anything stock would weaken identity, not improve it.
- Nebula/planet/particles/grain/grids are drawn in code (starfield canvas,
  OGL aurora + shader demos, CSS meshes), which keeps them theme-aware,
  animatable, lightweight and licence-free — better than a static download on
  criteria 4, 5 and 7.
- No section was found where a downloaded image materially beat the
  code-generated treatment, so nothing was added. This file stays the single
  record; any future external asset must be listed here with source and
  licence.
